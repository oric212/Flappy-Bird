# Flappy Bird

A small Flappy Bird-inspired arcade game built in Unity.

## Features

* Physics-based flap controls
* Endless scrolling ground and background
* Procedurally generated pipe obstacles
* Standard, asymmetric, top-only, and bottom-only pipes
* Coins and temporary Sonic speed boosts
* Arcade Features toggle
* Score and high-score tracking
* Main Menu and Game Over UI
* Music and sound-effect controls
* Keyboard and mouse support

## Controls

* **Space / Left Click** - Flap
* **Mouse** - Navigate menus and settings

## Arcade Mode

When Arcade Features are enabled:

* Coins give bonus score
* Sonic pickups temporarily increase movement speed

They can be disabled from the Main Menu for a more traditional Flappy Bird-style experience.

## Built With

* Unity `6000.3.20f1`
* Universal 2D / URP
* C#

## Running the Project

1. Clone the repository.
2. Open it with Unity `6000.3.20f1` or a compatible Unity 6 version.
3. Open:
   `Assets/Scenes/FlappyBird.unity`
4. Press Play.
